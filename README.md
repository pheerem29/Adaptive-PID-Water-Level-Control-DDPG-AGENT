# Adaptive-PID-Water-Level-Control-DDPG-AGENT
This repository contains the MATLAB/Simulink R2023a implementation of an adaptive PID controller for nonlinear industrial water-level systems. Because standard PID controllers use fixed gains, their performance often degrades as water levels and plant dynamics change.   To solve this, a Deep Deterministic Policy Gradient (DDPG) reinforcement learning agent was trained over 2,000 episodes to continuously output incremental changes to the PID gains based on real-time operating conditions. When evaluated across 50 randomized scenarios, the DDPG-based controller reduced the average settling time by 45.4% and the average rise time by 14.6% compared to a conventional, fixed-gain PID controller. By reaching desired set-points much faster, this adaptive approach helps minimize process downtime, lower pump operating time, and decrease energy consumption in industrial applications.
